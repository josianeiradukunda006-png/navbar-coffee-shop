# Aroma & Bean Café — React multi-page assignment

A beginner-friendly React website using React Router v6 and standard CSS.

## Pages
- Home
- Menu (search, category filter, popular-only filter, and sorting)
- Roastery & Beans
- About Us
- Events & Workshops (filter by event type)
- Loyalty & Rewards (interactive sample points dashboard)
- Table Reservations (validated demo form)
- Contact & Locations (contact details and feedback form)
- Directory & Legal
- Not Found page

## Run the project
1. Install Node.js.
2. Open this project folder in VS Code.
3. Open a terminal and run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

## Important notes
This is a frontend student-project demo. Reservation and contact forms do not send data to a server. Rewards points reset when the page refreshes. Prices, events, email, phone, and location are sample content and should be replaced with verified details.

## Useful files
- `src/App.js`: routing between pages.
- `src/components/Navbar.js`: shared navigation.
- `src/components/Footer.js`: shared footer.
- `src/data/menuItems.js`: menu data.
- `src/pages/Menu.js`: search, filtering, and sorting.
- `src/pages/Rewards.js`: interactive rewards demonstration.
- `src/pages/Reservations.js`: reservation form.
- `src/pages/Contact.js`: contact/feedback form.
- `src/App.css`: styling and responsive layout.
